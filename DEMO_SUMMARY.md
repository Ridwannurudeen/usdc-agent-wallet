## 🎯 How to Record (Quick Version)

### Easiest Method (Phone):
1. Clean your terminal (clear screen, big font)
2. Run: `./video-demo.sh`
3. Start phone video recording of your screen
4. Let it play through (~3-4 minutes)
5. Upload to YouTube/Loom

### Professional Method (Screen Recorder):
```bash
# Mac: Use QuickTime (built-in)
# Linux: Use SimpleScreenRecorder or OBS
# Windows: Use OBS or Xbox Game Bar

./video-demo.sh
```

### Terminal Recording (asciinema):
```bash
# Install asciinema first
asciinema rec demo.cast
./video-demo.sh
# Ctrl+D to stop
asciinema upload demo.cast
```
