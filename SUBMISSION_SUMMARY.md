## 📊 Technical Specs

**Language:** JavaScript (Node.js)  
**Framework:** OpenClaw skill  
**Libraries:** Ethers.js v5.7  
**Chains:** 8 (4 mainnets + 4 testnets)  
**Functions:** 5 core + CLI  
**LOC:** ~400 (core implementation)  
**License:** MIT

**Supported Operations:**
- `getBalance(address)` - Check USDC balance
- `send({ to, amount, memo })` - Send USDC payment
- `getHistory(address, limit)` - View transactions
- `simulate({ to, amount })` - Dry-run transaction
- `getAddress()` - Get wallet address

**Supported Chains:**
- Ethereum (+ Sepolia testnet)
- Base (+ Sepolia testnet)
- Polygon (+ Amoy testnet)
- Arbitrum (+ Sepolia testnet)
